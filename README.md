# ReactionSketch

有機化学のレポート向けの、構造式と反応機構のエディタです。ChemDraw の代わりに使うことを目指しています。
ブラウザで動く Web アプリです。インストールは要らず、作業内容はこのブラウザの中に保存されます。

## できること

- 構造式の 2D 描画: ACS Document 1996 の書式 (結合長 14.4 pt、線幅 0.6 pt、Arial 10 pt) で描画します。
  - 単結合・二重結合・三重結合、くさび・破線くさび・波線
  - 環 (4〜8 員環、ベンゼン環、いす形シクロヘキサン)、炭素鎖
  - 二重結合の線の位置は自動で決まります (環の内側、末端の C=O は中央など)
  - 電荷 (⊕ ⊖ の丸囲み表示も可)、非共有電子対、ラジカル、原子番号
  - 略号: Me, Et, Ph, Bn, Ac, Boc, Ts, TBS, OMe, CO2Et, NHBoc など。結合の向きに応じて CO2Et → EtO2C のように自動で反転し、展開もできます
  - 原子価を超えた原子は赤い点線の丸で示します (書き出す画像には出ません)
- 反応機構
  - 曲がった矢印 (電子対・1 電子) を、原子・非共有電子対・結合から行き先へドラッグして描きます。矢印は分子と一緒に動きます
  - 中央の ○ をドラッグすると曲がり具合を変えられ、両端をドラッグすると付け替えられます
  - 反応矢印: 通常 →、平衡 ⇌、逆合成 ⇒、共鳴 ↔、「進行しない」
  - 遷移状態の括弧と ‡、＋記号、化合物番号 (1, 2 …)
- 矢印から次の構造を自動で作る (Ctrl+Enter): 描いた曲がった矢印 (電子対・片羽) のとおりに結合の生成・切断と形式電荷・ラジカルを計算し、反応矢印の右に中間体・生成物を作ります。結合の生成・切断がなければ共鳴矢印 ↔ になります。C–Mg や B–H のような分極した結合は、電気陰性度の大きい側が攻撃します
- 高分子: 繰り返し単位の括弧 [ ]n、末端 (*)、モノマーの C=C を開いて繰り返し単位を作る「重合」、単位の式量と重合度 n から Mn の計算。例題: スチレンのラジカル重合、ポリ酢酸ビニルのけん化、ナイロン 66
- 試薬表・収率計算: 反応式から分子を取り込み、基質の量と当量から必要量 (mg・mL) を計算、生成物の質量から収率を計算します。反応条件の試薬・溶媒も辞書から追加でき (液体は密度も入ります)、表は Word・Excel に貼り付けられます。実験項向けの 1 行の要約もコピーできます
- 立体: R/S・E/Z の表示 (くさび結合から自動判定)。テンプレート: Newman 投影式、いす形シクロヘキサン (アキシアル・エクアトリアル)、Fischer 投影式 (グリセルアルデヒド・グルコース)、Haworth 式。立体異性体の列挙 (R/S・E/Z・メソ)、共鳴構造・互変異性体の探索もできます
- 右クリックメニュー: 原子・結合・矢印ごとによく使う操作 (右ドラッグは画面の移動)
- 反応条件: 矢印の上下に書けます。H2SO4 や CH2Cl2 の数字は自動で下付きになり、n-BuLi・t-BuOK・(R) は自動で斜体、-78 °C の「-」は「−」になります。`_{…}` で下付き、`^{…}` で上付き、`*…*` で斜体を指定できます
- 名前から構造を探す (検索欄、Ctrl+F。入力の履歴も残ります)
  - 内蔵辞書 (オフラインでも使用可): 溶媒・試薬・基本的な化合物 約 170 種。日本語名・英語名・略号 (THF, DMF, LDA …) に対応
  - SMILES / InChI / Molfile
  - IUPAC 名 → OPSIN、慣用名・CAS 番号 → PubChem、日本語名 → Wikidata (いずれもオンライン時)
- 手動の整列
  - 構造を整える (Ctrl+Shift+K): RDKit で座標を作り直します
  - 反応式を並べる (Ctrl+L): 分子・＋・反応矢印を左から順に等間隔に並べ、上下の中央を揃えます。矢印の長さは条件の文字の幅に合わせます
- タブ: 反応ごとにタブを分けて管理できます。ダブルクリックで名前を変更し、ドラッグで並べ替えます。閉じたタブは開き直せます
- 分子の情報: 分子式・分子量・精密質量を表示し、HRMS の計算値の文をコピーできます (例: `HRMS (ESI) m/z calcd for C9H8NaO4 [M+Na]+: 203.0315`)。SMILES の表示と、PubChem での名前 (IUPAC 名) の検索もできます
- 例題 (11 種): SN2、E2、アルドール付加、Diels–Alder、Grignard 付加、エノラートの共鳴、ラジカル開裂 (片羽矢印)、多段階合成、スチレンのラジカル重合、ポリ酢酸ビニルのけん化、ナイロン 66。改変してすぐ使えます
- 自動描画 (メニュー「自動描画」、Ctrl+K で名前を入れても出せます)
  - テキストから描く: 化合物名・示性式・日本語の体系名・スキーム記法を入力すると、プレビューを見ながらまとめて描きます。「原料 -> 生成物 ; 矢印の上 ; 矢印の下」の形で書き (→ ＋ ； も可)、生成物を ? にすると自動で予測します。矢印が 1 つもない入力は、化合物の一覧として並べます。例のチップから入力できます
  - 反応機構を描く: 反応式から曲がった矢印つきの機構を下に作ります。内蔵の多段階の機構が 16 種 (SN2・SN1 など)、自分の基質に当てはめるテンプレートが 30 種 (SN2、E1・E2、付加、還元、Grignard、アセタール、エステル化、アルドール、Claisen、芳香族求電子置換、エポキシドの開環など) あり、それ以外は 1 段階で表します。ラジカル反応 (hν・AIBN・NBS など) は開始・成長・停止の連鎖を片羽の矢印で描きます
  - 生成物を予測: 原料と矢印の上下の試薬から、生成物を矢印の右に描きます
  - 反応条件・試薬を提案、逆合成を提案 (1 段の切断と前駆体の候補。⇒ の逆合成式として描く)
  - 反応式の係数を合わせる、反応前後の原子の位置をそろえる、重合 (モノマー → 高分子)
  - 投影式・配座への変換: Fischer 投影式、いす形 (環反転も)、Newman 投影式、Haworth 式
  - 自動整列: 行を保ったまま並べる、A4 の幅や半分の幅 (2 段組) で折り返して並べる、まとめて整える (結合長・整列・重なり)
- 探す
  - コマンド検索 (Ctrl+K): すべての操作・化合物・人名反応・ヘルプの項目を、かな・ローマ字・英語でも探して実行します
  - 使い方 (F1): 分類ごとの項目とショートカット一覧。検索もできます
  - 反応ライブラリ: 内蔵の人名反応など約 210 件を分野ごとに見て、反応式として挿入できます。検索欄に「r アルドール」と入れても置けます
  - はじめての画面とはじめてガイド: 初回に基本の操作を案内します (ヘルプメニューから再表示できます)
  - テンプレート集 (環・アミノ酸・糖・保護基・試薬など)、ペプチド・DNA・RNA を配列から作る機能もあります
- 保存と安全
  - 作業内容はブラウザ内 (IndexedDB) に自動で保存されます。サーバーには送られません
  - 版の履歴: 自動で版が残り (5 分ごと、同じ中身は残しません)、「履歴から復元」で過去の状態に戻せます。名前を付けて手動で残すこともでき、復元の前の状態も自動で残ります
  - 閉じたタブは Ctrl+Shift+T で開き直せます
  - 共有リンク: 図をリンク 1 つにします。データはリンクの中 (# 以降) に入り、サーバーには送られません。リンクを知る人は誰でも見られるので、共有先に気を付けてください。大きすぎる図はリンクにできません
  - 他人のファイルや共有リンク・貼り付けたデータを開くときは、読み込み時に中身を検証し、知っている項目だけを取り込みます (壊れた要素や大きすぎるデータは捨てる・断る)
- 書き出し (Ctrl+Shift+E)
  - PNG (解像度 150 / 300 / 600 dpi、背景を透明にもできます)、SVG、PDF (このタブ、または全タブを 1 タブ 1 ページで)、ChemDraw CDXML、MOL、SDF、RXN
  - PNG をクリップボードにコピー (Ctrl+C): そのまま Word に貼れます。解像度を PNG に記録するので、Word に貼ると ACS の原寸で入ります
  - SMILES・InChI・InChIKey・反応 SMILES・Molfile・SMARTS・CXSMILES を文字列でコピー、印刷 (Ctrl+P)
  - すべてのタブを 1 つのファイル (.rsketch) に保存し (Ctrl+S)、読み込めます。.cdxml・.mol・.sdf・.rxn・.smi も開けます (画面へのドラッグ & ドロップも可)
- 設定 (Ctrl+,): テーマ (自動・ライト・ダーク)、文字とボタンの大きさ (小・標準・大)、キャンバスのグリッド、書き出しの解像度と背景、塩の描き方、自動整列の折り返し幅、反応式の範囲の表示
- インストールすると、オフラインでも使えます (PWA。https で開いたとき)

## 速く描くための操作

| 操作 | 内容 |
|---|---|
| 原子にカーソルを合わせて `O` `N` `S` `L`(Cl) `B`(Br) `M`(Me) `Y`(Ph) | 元素・略号を変更 |
| 原子に合わせて `+` `-` `:` `.` | 電荷・非共有電子対・ラジカル |
| 原子に合わせて `Enter` / ダブルクリック | ラベルを入力 (OMe, CO2Et, NH2, N+ …) |
| 結合に合わせて `1` `2` `3` `W` `H` `Y` `D` | 次数・立体・二重線の位置 |
| 結合ツールで原子をクリック | 最適な向きに結合を伸ばす (ジグザグになります) |
| `V` `E` `L`(投げ縄) `1` `2` `3` `W` `H` `Y` `C` `B` `4`〜`8` `A` `F` `R` `P` `T` `N` `K` | ツールの切り替え |
| `Ctrl+Z` / `Ctrl+Y`、`Ctrl+D`、`Delete`、矢印キー | 元に戻す / やり直す、複製、削除、少し動かす |
| `Ctrl+K` | コマンド検索 (すべての操作を名前で探す) |
| `Ctrl+L` / `Ctrl+Shift+K` / `Ctrl+Enter` | 反応式を並べる / 構造を整える / 曲がった矢印から次の構造を作る |
| `Ctrl+Shift+E` / `Ctrl+S` / `Ctrl+,` / `F1` | 書き出し / すべてのタブを保存 / 設定 / 使い方 |

`F1` (または `?`) か、上のバーのヘルプメニューの「使い方」で一覧を表示できます。タッチパッドの 2 本指で画面を移動、ピンチやCtrl+ホイールで拡大縮小します。スマホやタブレットでは、1 本指で描き、2 本指で移動・拡大縮小します。

## 開発

必要なもの: Node.js 20 以上 (React 19・Vite・TypeScript)

```bat
npm install
npm run dev      :: http://localhost:5175 で起動 (run_dev.bat でも可)
npm test         :: 単体テスト (RDKit を含む)
npx tsc --noEmit :: 型の検査
npm run build    :: dist/ に公開用ファイルを作る
```

| フォルダ | 内容 |
|---|---|
| `src/model/` | ドキュメントの形式・編集操作・分子式の計算 |
| `src/render/` | ACS 書式での描画 (ラベル配置・二重結合・矢印・SVG) |
| `src/editor/` | 状態管理 (タブ・元に戻す・自動保存)・キー操作・当たり判定 |
| `src/chem/` | RDKit (WebAssembly) との連携、名前検索、内蔵辞書、Molfile、反応機構・生成物予測・逆合成 |
| `src/io/` | PNG / SVG / PDF / CDXML などの書き出しと読み込み・共有リンク・読み込み時の検証 |
| `src/ui/` | 画面 (React)・使い方の内容 |
| `src/auto/` | 自動描画 (テキストから描く・折り返し整列・投影式と配座への変換) |

### GitHub Pages で公開

`deploy_github.bat` を使います。初回の準備は bat の中に書いてあります。
